# Experiment configurations

Committed configuration files will live here once their schemas are introduced.
Use descriptive immutable names, for example:

```text
engine_smoke_v1.yaml
3p_specialist_v1.yaml
4p_specialist_v1.yaml
unified_3p4p_v1.yaml
unified_rules_mix_v1.yaml
```

Generated checkpoints and replay shards belong under
`runs/kingdomino_classic/`, not in this directory.
